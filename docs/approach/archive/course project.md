Course project

Overview:

A term-long group project that exercises the steps involved in designing, implementing and evaluating a scalable computer system (software, hardware or co-design).

Student groups have the flexibility of choosing the problem, hardware platform (e.g., parallel shared memory or shared-noting distributed) and implementation framework.

It is important that the proposed solution is technically sound and experimental methodology is justifiable (e.g., test bed, choice of dataset and evaluation metrics).

Depending on the class size, each group will have up to 3, 4 or 5 members.

The course project is worth 45% of the total grade:

Project proposal 5%
Project presentation 20%
Project report 20%

Project deliverables (due dates will be posted on LEARN):

Project proposal - a brief description of the problem of interest, its scalability requirements, overview of anticipated solution design, research methodology and work plan. Please try to cite related work found in the literature, e.g, ACM Digital Library and IEEE Xplore. Please include names of all group members. 

Resources:
A well known guide to writing short research proposals. 
On the art of writing proposals.

Project presentation - A group presentation of the completed project; followed by a ~3-minute Q&A. All group members are required to participate in the presentation. Please feel free to use the conference presentation slide decks listed here as reference to structure your own presentation. (If you want to use UWaterloo/ECE presentation templates, you can download them from here.) Note that after the project presentation, you are free to update/improve your implementation and project report.

Project report - problem definition and context, scope of contribution, solution design (rationalize design choices and the implementation approach), evaluation methodology (including datasets used for evaluation) and results, and future work. Also, try to highlight how your contribution compares with the state-of-the art or at least key related work found in the literature. The report should be at least 4 pages including references in the IEEE double column format (download Word/LaTex templates from here). If required, you can add an appendix.

Implementation - upload your code to LEARN dropbox (in a zip file or a tarball) . Include a brief “how-to” document that provides instructions on how to run your code on the target hardware platform. The document should provide enough details to help reproduce the experiments in the project report; also, include download URL/file location of the datasets. Please do not upload input datasets or large output files to LEARN dropbox. Do keep a backup copy of your code, for example on GitLab: git.uwaterloo.ca. Please do not post your code in a public repository (e.g., GitHub free tier).
